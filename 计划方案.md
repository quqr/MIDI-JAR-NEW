## 0. 修订版决策基线（已锁定，最严格口径）

| #   | 决策               | 结论                                                                                                        |
| --- | ------------------ | ----------------------------------------------------------------------------------------------------------- |
| 1   | Vue `<Transition>` | **全部移除**（ConfirmDialog / DrawerOutlet / SettingsDrawer 三处）                                          |
| 2   | hig-tokens         | **完全移除，不做映射** —— 直接删除全部 `--hig-*` 引用，不替换为 daisyUI token                               |
| 3   | CSS 动画           | **全部移除** —— `@keyframes`、`animation:*`、`transition:*` 声明一律删除                                    |
| 4   | 渲染层             | **排除** —— PixiJS(瀑布流) / VexFlow(五线谱) / @vue-flow(路由图) 属 canvas/SVG 绘图，非 HTML 控件，保持原样 |
| 5   | 控件来源           | **界面实现 = daisyUI 组件类名 + Tailwind 工具类**，零自定义样式、零手写 UI 控件                             |

**硬约束（术语基线）**

- 一律复用 daisyUI 既有组件（`btn`/`card`/`alert`/`modal`/`drawer`/`collapse`/`table`/`badge`/`toast`/`tooltip`/`input`/`select`/`fieldset`/`label`/`toggle`/`range`/`checkbox`/`radio`/`tabs`/`steps`/`timeline`/`stats`/`menu`/`navbar`/`dropdown`/`loading`/`skeleton`/`status`/`divider`/`stack`/`join`/`swap`/`rating`/`progress`/`kbd`/`link`/`avatar`/`chat`/`list`/`breadcrumbs`/`footer`/`hero`/`carousel`/`mockup-*`…）。

- 禁用清单：`<style scoped>`、`<style>`、`@keyframes`、`animation:`、`transition:`、`--hig-*`、自定义 class、任意 daisyUI v4 遗留类名。

## 2. “完全使用 daisyUI” 实施方案（需求 #4）

### 2.1 总原则

界面层只允许出现两类内容：

1. **daisyUI 组件类名**（如 `btn btn-primary`、`card`、`alert alert-info`、`modal`、`drawer`、`collapse`、`table`、`badge`）。
2. **Tailwind 工具类**（用于布局/间距/语义色：`flex`、`gap-2`、`p-4`、`text-base-content/70`、`bg-base-100`）。

不允许出现任何 `<style>` 块、自定义 class、`@keyframes`、`animation`、`transition`、`--hig-*`。

### 2.2 落地映射

| 场景        | 原写法（问题）                                           | daisyUI 写法                                                                         |
| ----------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 表单字段    | `form-control` + `label-text` + `select-bordered`        | `fieldset` + `label > span` + `select`（v5 默认有边框）                              |
| 开关        | `toggle` + `loading`                                     | 保留 `toggle`，`loading` 用 `loading loading-spinner`                                |
| 提示条      | `.midi-warning` 自定义                                   | `alert alert-warning`                                                                |
| 模态框      | `<dialog class="modal">` + `<Transition>` + 自定义过渡   | `modal` + `modal-box` + `modal-action`（去掉 Transition 包装）                       |
| 抽屉        | `fixed ... z-drawer` + `<Transition>` + `.drawer-*` 动画 | `drawer` + `drawer-side` + `drawer-end`（或用 Teleport + 条件渲染，去掉 Transition） |
| 状态点/徽标 | 自定义 `bg-[color]` + box-shadow                         | `status status-success` / `badge badge-soft`                                         |
| 空态        | 自定义                                                   | `empty-state` 公共组件（基于 daisyUI 排版）                                          |
| 加载        | 自定义 spinner                                           | `loading loading-spinner loading-md`                                                 |
| 间隔动画    | `.interval-cell` `@keyframes`                            | **直接删除动画**（需求 #6），保留纯静态列表                                          |
| 容器最大宽  | `max-w-[var(--hig-container-max)]`                       | `max-w-5xl`（或 `max-w-[64rem]` 固定值）                                             |

### 2.3 复用策略（需求 #3）

- **统一既有复用组件**：`components/Settings/*` 9 个组件的内部 v4 类名一次性整改为 v5；`common/*` 三个同样整改。
- **抽取新增公共片段**（重复出现的 UI 模式）：
  - `PageHeader`（标题 + 关闭/返回按钮行）
  - `SettingRow`（标签 + 描述 + 控件的统一行布局，替代各页面手写 `flex justify-between`）
  - `StateDot`（状态指示灯，替代 `AppNavbar` 里多处 `bg-[color]+box-shadow`）
  - `EmptyState` / `LoadingState`（已存在，统一调用）
- 所有页面**优先引用**这些公共组件，不再内联手写。

## 6. 风险点

- **视觉回归**：v4→v5 会改变 select/input 边框、alert 尺寸；间隔动画删除后列表为静态。
- **过渡删除的副作用**：抽屉/模态将瞬时出现（无淡入），功能不受影响。
- **hig 死引用删除**：当前即为断裂值，删除后样式回退到 daisyUI 默认，属修复。
- **渲染层误伤**：务必排除 PixiJS/VexFlow/@vue-flow，仅动 HTML UI。
- **CustomCursor**：删除 `transition` 后光标变“瞬时跟随”，需确认可接受。
