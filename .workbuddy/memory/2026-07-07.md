### 关键技术发现
- **Tailwind v4 `@theme` 不支持 `--duration-*` 命名空间**：`--duration-hig-fast: 150ms` 在 `@theme` 中不会生成 `duration-hig-fast` 工具类。必须用 `@utility` 显式定义。
- `@theme` 支持的命名空间：`--text-*`（字号）、`--radius-*`（圆角）、`--spacing-*`（间距）、`--ease-*`（缓动）、`--color-*`（颜色）等
- `@utility` 语法：`@utility duration-hig-fast { --tw-duration: var(--hig-duration-fast); transition-duration: var(--hig-duration-fast); }`

### 瀑布流钢琴设置页无法滚动（BUG 修复）
- **根因**：`WaterfallPianoSettings` 是**唯一**未用 `SettingsSection` 包裹的设置页
- `SettingsSection` 提供滚动容器：外层 `h-full flex flex-col overflow-hidden` + 内层 `flex-grow-1 overflow-y-auto p-4`
- 该页根节点原本是 `<div class="p-4 space-y-4">`（无 `h-full`/`overflow-y-auto`），内容溢出 `SettingsLayout` 的 `flex-1 min-h-0` 父容器却无滚动条 → 页面无法滚动
- **修复**：用 `<SettingsSection :show-reset="false">` 包裹（页面自带重置按钮，故不显示 footer），根 div 去掉 `p-4`（由 SettingsSection 提供），保持 `space-y-4`
- 其他设置页（General/Notation/ChordDisplay/Cursor）均用 `SettingsSection` 故滚动正常 → 印证此页缺包裹即 bug

### 关键约定（后续参考）
- 新增设置页**必须**用 `SettingsSection` 包裹，否则无法滚动
- `SettingsSection` 的 `show-reset` 默认 true 会显示底部重置按钮；页面自带重置逻辑时传 `:show-reset="false"`
