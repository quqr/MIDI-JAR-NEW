本文档基于对 src/views/ 下全部 15 个页面级组件的逐行源码审计， 依据 Apple HIG 与 Material Design 3 通用原则， 从「视觉层级 · 间距节奏 · 触达与无障碍 · 动效反馈 · 深浅色适配 · 响应式与密度」六个维度， 产出可落地的 Token 规范、逐页 before/after 标注图与分优先级实施清单。

最严重的系统性问题：DaisyUI v4 变量误用 多处直接写 oklch(var(--b2)) / oklch(var(--bc) / 0.7)。 DaisyUI v4 的 CSS 变量是不含百分号的纯数字（如 --b2: 90%）， 正确写法是 oklch(var(--b2) / 1) 或使用语义类 bg-base-200。 当前写法会导致背景透明 / 文字不可见，属 P0。
最普遍的一致性问题：Magic Number 泛滥 text-3xl、gap-6 md:gap-20、min-h-[150px]、text-[10px] 等硬编码值散落在各页面，既无语义也无统一节奏。 text-[10px] 更直接违反 HIG 最小可读字号（13px）底线。
已有的良好基础 项目已具备 i18n 全覆盖、prefers-reduced-motion 降级、 语义化 role="status" / aria-label 广泛使用、 Tauri 拖拽区与窗口控制完善。优化以「补齐 Token 层 + 修 Bug + 统一节奏」为主，非推倒重来。

2HIG 六维度评估框架

每个页面将按以下六个维度逐一评估，每维度给出「现状 → 问题 → 建议」：

① 视觉层级 Visual Hierarchy
字号阶梯、字重对比、色彩权重是否引导用户注意力到正确位置。核心：标题/正文/辅助文字的 3 级以上可感知差异。
② 间距节奏 Spacing Rhythm
内/外边距是否基于统一基线（4px 或 8px 倍数），卡片间距、列表行距、区块留白是否形成可预测的节奏感。
③ 触达与无障碍 Touch & A11y
点击目标 ≥ 40px（桌面可放宽至 32px）、键盘可达、焦点可见、aria 语义完整、对比度 ≥ 4.5:1、最小字号 ≥ 13px。
④ 动效反馈 Motion
交互态（hover/press/focus）有即时反馈，过渡时长在 100–250ms 区间，动效遵循缓动曲线，且尊重 reduced-motion。
⑤ 深浅色适配 Theming
所有颜色通过语义变量引用，无硬编码色值（除语义状态色），深色模式下对比度与可读性自动保持。
⑥ 响应式与密度 Responsive
断点切换平滑，窄屏不裁剪关键信息，宽屏不浪费空间；信息密度随视口自适应。

4Token 扩展规范

在现有 DaisyUI 主题基础上，扩展以下语义 Token 层。所有页面应只引用 Token，禁止裸值。

4.1 字号阶梯（Type Scale）

/* src/styles/hig-tokens.css — 追加到现有主题 */
:root {
  /* 字号：12 级阶梯，最小 13px 保证可读 */
  --hig-text-2xs: 11px;   /* 仅用于 label tag / 胶囊角标，不可用于正文 */
  --hig-text-xs:  12px;   /* 辅助提示 */
  --hig-text-sm:  13px;   /* 次要正文、表格单元格 */
  --hig-text-base: 14px;  /* 正文基准 */
  --hig-text-md:  16px;   /* 强调正文 */
  --hig-text-lg:  18px;   /* 小标题 */
  --hig-text-xl:  22px;   /* 区块标题 */
  --hig-text-2xl: 28px;   /* 页面标题 */
  --hig-text-3xl: 36px;   /* 展示型标题 */
  --hig-text-4xl: 48px;   /* 焦点展示（和弦名） */
  --hig-text-5xl: 64px;   /* 全屏 hero（fluid clamp 下限） */

  /* 行高 */
  --hig-leading-tight: 1.2;   /* 大标题 */
  --hig-leading-normal: 1.5;  /* 正文 */
  --hig-leading-relaxed: 1.65; /* 长文阅读 */
}

  --hig-space-7: 48px;  /* 分区间距 */
  --hig-space-8: 64px;  /* hero 级留白 */

:root {
  --hig-radius-sm: 6px;   /* 输入框、小按钮、badge */

  --hig-target-md: 40px;  /* 标准按钮 */
  --hig-target-lg: 44px;  /* 触屏优先按钮 */

4.5 动效曲线与时长（Motion）

:root {
  /* 时长 */
  --hig-duration-instant: 80ms;   /* 颜色变化 */
  --hig-duration-fast: 150ms;    /* hover、小型过渡 */
  --hig-duration-normal: 220ms;   /* 标准过渡 */
  --hig-duration-slow: 320ms;     /* 入场动画、大型位移 */

  /* 缓动曲线 */
  --hig-ease-standard: cubic-bezier(0.2, 0, 0, 1);      /* 默认 */
  --hig-ease-emphasized: cubic-bezier(0.3, 0, 0, 1);   /* 强调入场 */
  --hig-ease-exit: cubic-bezier(0.4, 0, 1, 1);          /* 退场 */
}

@media (prefers-reduced-motion: reduce) {
  * { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; }
}

:root {

  --hig-success-container: oklch(95% 0.03 145);
  --hig-warning: oklch(72% 0.16 70);
  --hig-warning-container: oklch(95% 0.04 70);

  --hig-error-container: oklch(95% 0.03 25);
  --hig-info: oklch(60% 0.13 230);
  --hig-info-container: oklch(95% 0.02 230);

/* 深色模式自动反转 container 明度 */
[data-theme="dark"] {

6跨页面通用模式

6.1 SettingsCollapse 复用模式

设置页大量复用 SettingsCollapse + SettingsToggle/Select/Range/ColorPicker 组件体系。这是最佳实践，应确保：

  • 所有子控件 label 关联（aria-label 或 <label for>）
  • Collapse 触发器是 button 元素，aria-expanded 联动
  • Toggle 用 role="switch" + aria-checked
  • Range 补 aria-valuetext
  • RadioGroup 用 role="radiogroup" + 方向键支持

6.2 长表单导航模式

ChordDisplayModuleSettings、WaterfallPianoSettings（1268 行）是超长表单。建议统一引入页内锚点 TOC模式：

方案：顶部 sticky 横向锚点条，点击跳转到对应 SettingsCollapse 分组，滚动时高亮当前分组（IntersectionObserver）。

6.3 状态色统一

当前状态色分散：AppNavbar 硬编码 oklch、Debugger 用 text-info/warning/error/success、Routing Wire 用 hsl。应统一到 --hig-success/warning/error/info 四色体系。

6.4 点击目标底线

全项目 btn-xs(24px) 应替换为 btn-sm(32px) 起步。仅在空间极度受限的工具栏内保留 btn-sm，绝不使用 btn-xs 作为可交互目标。
