# ADR-001: Application Icon Design

## Status

Accepted

## Context

MIDI-JAR 是一个跨平台 MIDI 键盘工具，主要功能包括：

- 和弦检测
- 瀑布流钢琴（Waterfall Piano / Synthesia 风格）
- MIDI 文件播放

原有的应用图标采用写实风格的合成器设备外观，包含显示屏、按钮和钢琴键。随着项目发展，需要一个新的图标来更好地传达项目核心功能并符合现代设计趋势。

## Decision

设计全新的应用图标，采用以下规格：

### 视觉风格

- **现代简约**：扁平化设计，简洁线条，配合细节层次
- **圆角方形**：iOS/macOS 风格的圆角正方形轮廓

### 核心元素

- **瀑布流音符块**：4条长条形音符块，位于图标上半部分，使用项目 pitch 配色风格
- **钢琴键**：精确的黑白钢琴键布局（一个完整八度 C-B + C），黑键位置符合真实钢琴

### 背景效果

- **流体模拟光晕**：多层径向渐变模拟流体动态效果（#6366f1、#14b8a6、#f59e0b、#ec4899、#8b5cf6）
- **粒子效果**：8个半透明粒子点，模拟音乐可视化
- **流动曲线**：三条贝塞尔曲线，增强流动感

### 细节增强

- **钢琴键渐变**：白键使用白色到浅灰渐变，黑键使用深灰渐变
- **音符块高光**：顶部高光条，增强立体感
- **阴影效果**：钢琴键阴影、音符块发光效果
- **边框高光**：顶部微弱高光边框

### 色彩方案

- **pitch 配色**：采用项目默认配色（#6366f1 低音、#14b8a6 中音、#f59e0b 高音）
- **深色背景**：#0f172a（深蓝灰色）
- **边框**：#1e293b（稍浅的蓝灰色）

### 输出格式

- SVG 源文件（128x128 viewBox）
- PNG 各尺寸（16x16 至 1024x1024）
- ICO（Windows）
- ICNS（macOS）
- Android mipmap 资源
- iOS AppIcon 资源

## Consequences

### 正面

- 图标更清晰地传达瀑布流钢琴这一核心功能
- 现代简约风格符合当前设计趋势
- 柔和彩虹色系在保持辨识度的同时不会过于刺眼
- 跨平台一致性良好

### 负面

- 与原有的写实风格差异较大，可能需要用户适应
- 彩虹色在某些单色显示场景下可能不如纯色图标清晰

## Alternatives Considered

1. **保持原有写实风格**：与项目发展方向不符，原图标过于复杂
2. **纯色设计**：缺乏辨识度，无法体现瀑布流的动感
3. **六边形或其他几何轮廓**：与主流应用图标风格不一致
4. **鲜艳纯色彩虹**：过于刺眼，不适合长时间使用

- 文件位置：`src-tauri/icons/icon.svg`
- 生成命令：`npx tauri icon src-tauri/icons/icon.svg --output src-tauri/icons`
