# Ticket: 音色管理 UI 设计

**Label:** wayfinder:prototype
**Parent:** 010-map-audio-smplr
**Status:** Open
**Blocked by:** 012-sampler-architecture-design

---

## Question

需要设计 `/sampler` 路由视图的音色管理界面:

1. **布局结构**: 主界面如何布局?侧边栏音色列表 + 主区域播放控制?还是标签页切换?
2. **音色浏览器**: 如何展示 128 个 GM 音色?分类浏览(钢琴、弦乐、打击乐)?搜索功能?收藏功能?
3. **音色状态指示器**: 在哪里显示当前音色和加载状态?(顶部栏?侧边栏?)
4. **加载进度**: 如何显示音色加载进度?(进度条?百分比?动画?)
5. **音色切换**: 切换按钮在哪里?如何防止用户在加载中误操作?
6. **缓存管理**: 缓存大小、清除缓存的 UI 在哪里?(设置面板?)
7. **用户音色库**: 如何展示用户导入的音色?导入按钮在哪里?
8. **播放控制**: 需要虚拟钢琴键盘吗?MIDI 输入状态指示?
9. **响应式设计**: 在移动端如何适配?

## Resolution

基于原型探索,确定了 UI 设计方案:

### 设计决策

**选择方案**: 混合方案 - 卡片网格布局 + 侧边栏详情

**理由**:

- 卡片网格直观展示音色,适合浏览和发现
- 侧边栏提供详细信息和快捷操作,不遮挡主界面
- 响应式设计友好,移动端可折叠侧边栏

### 核心组件

1. **顶部状态栏**:
   - 当前音色名称和图标
   - 加载进度条(进度条 + 百分比)
   - 缓存大小显示
   - 快捷操作按钮(刷新、清空缓存)

2. **音色浏览器**:
   - 搜索框(实时搜索)
   - 分类过滤器(标签页或下拉菜单)
   - 收藏功能(星标按钮)
   - 排序选项(按名称、类别、使用频率)

3. **音色卡片**:
   - 音色名称和图标
   - 类别标签
   - 状态徽章(已加载/加载中/未加载)
   - 快捷按钮(加载、播放预览、收藏)

4. **侧边详情面板**:
   - 音色详细信息(音色描述、采样数、大小)
   - 音色参数调节(音量、声像、混响)
   - 虚拟钢琴键盘(快速试音)
   - MIDI 输入状态指示

5. **底部播放控制**:
   - 虚拟钢琴键盘(可隐藏)
   - 音符历史记录
   - 快捷音符按钮

### 响应式设计

- **桌面端**(≥1024px): 卡片网格(4列) + 侧边详情面板
- **平板端**(768-1023px): 卡片网格(3列) + 可折叠侧边栏
- **移动端**(<768px): 列表视图 + 模态详情面板

### 交互细节

- **音色切换**: 点击卡片切换,显示加载动画
- **加载进度**: 进度条 + 百分比数字
- **缓存管理**: 设置面板中的"存储"标签页
- **错误处理**: 加载失败时显示 Toast 通知,回退到默认音色
